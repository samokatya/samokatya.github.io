Customer Churn Prediction

Python & Logistic Regression

This project uses customer usage data to predict churn using logistic regression. Exploratory data analysis and preprocessing were done with Pandas and Seaborn.

Tools Used

  • Python
  • Pandas, Matplotlib, Scikit-learn

Key Insights

  • High monthly charges increase churn risk
  • Tenure is a strong predictor
